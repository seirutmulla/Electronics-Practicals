# Electronics-Practicals
This repository contains all programming practicals completed as part of my B.Sc coursework (ongoing)

Group: A
1. To write C programming for interfacing the thumbwheel & seven segment display.
2. To write C programming for interfacing LCD to Microcontroller.
3. To write C programming for waveform generation using DAC Interface.
4. To write Arithmetic, logical & code conversion problems using Python Language.
5. Raspberry Pi OS Installation and Configuration
6. To study the interfacing of light emitting diode with Raspberry Pi 3 B+ using Python program.

Group: B
7. To interface the LED and push button to Raspberry Pi and write a Python Programming to control the LED and push button.
8. Interface the LDR to Raspberry Pi and write python program to measure the resistance of LDR.
9. Interface PIR Sensor and buzzer to Raspberry Pi and write python program to give sound alarm whenever detect an intruder using PIR sensor module
10. Interface the Ultrasonic Sensor to Raspberry Pi and write Python Program to measure distance using the ultrasonic sensor.
11 Interface the LCD to Raspberry Pi and write Python Program to display messages.
12 Interface the Temperature and Humidity sensor (DHT11) to Raspberry Pi and write Python Program to display messages.
